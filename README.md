# projects
The Student Management System is a simple web-based application developed using HTML, CSS, and JavaScript. It allows users to manage student records by adding and deleting student information through an easy-to-use interface.

This project was created to demonstrate fundamental web development concepts, including user interface design, form handling, DOM manipulation, and data management.

## Features

- Add new student records
- Display student information in a table
- Delete student records
- User-friendly interface
- Responsive and clean design

## Technologies Used

- HTML5
- CSS3
- JavaScript
